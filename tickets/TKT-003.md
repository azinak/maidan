## المطلوب
فريق التسويق يريد أكواد خصم. أنشئ `makhzan/discounts.py` بهذه الواجهة بالضبط:

```python
class DiscountError(Exception): ...

@dataclass(frozen=True)
class Discount:
    code: str
    kind: str                  # "percent" أو "fixed"
    value: str                 # "10" تعني 10% إذا كان percent، أو 10 ريالات إذا كان fixed
    min_subtotal: Money = ZERO
    expires: date | None = None   # آخر يوم صالح (شامل)
```

وأضف إلى `Order`:
- `apply_discount(discount: Discount, today: date) -> None`
  - ترفع `DiscountError` إذا انتهت صلاحية الكود (today بعد expires)، أو كان المجموع أقل من `min_subtotal`،
    أو كان على الطلب خصم مطبّق مسبقًا (لا يُجمع خصمان).
  - ترفع `ValueError` إذا كان `kind` غير معروف.
- `discount_amount() -> Money`: قيمة الخصم الحالية (صفر إن لم يوجد خصم).
  - الخصم بالنسبة يُقرَّب نصف للأعلى لأقرب هللة.
  - الخصم الثابت لا يتجاوز مجموع الطلب أبدًا.

## قواعد الحساب
- الضريبة 15% تُحسب على (المجموع − الخصم).
- `total() = subtotal() − discount_amount() + vat()`
- الفاتورة تعرض سطر الخصم إن وُجد.
